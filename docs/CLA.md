# Contributor License Agreement

BioFlow's public core is Apache 2.0. To preserve inbound licensing flexibility for future commercial offerings, external contributions require CLA approval before merge.

This document describes the workflow. It is not the legal agreement itself.

## Workflow

1. Open a pull request against the public core.
2. Read `CONTRIBUTING.md`.
3. If this is your first external contribution, contact `founders@bioflow.io` and the maintainers to complete the CLA step.
4. Maintainers confirm CLA status before merging.

## GitHub Enforcement

- The repository runs `.github/workflows/cla.yml` on pull requests.
- External pull requests pass only after a maintainer applies the `cla-approved` label.
- Repository members, owners, and collaborators pass automatically.
- Branch protection on `main` requires the `CLA` status check before merge.

## Policy

- Apache 2.0 remains the repository license.
- The CLA only affects inbound licensing and relicensing rights.
- Repository maintainers do not merge external changes until CLA status is confirmed.
