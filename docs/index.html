How it works

1) Normalize

  • Run bioflow tidy with a deterministic profile.
  • Outputs are written to a local content-addressed store.
  • Produces a run manifest + execution record.

2) Verify

  • bioflow verify recomputes the audit chain.
  • Re-hashes artifacts and checks integrity.
  • Replays deterministically and compares digests.

3) Sync

  • Push/pull runs across machines without trusting spreadsheets.
  • Service boundary uses Postgres RLS for tenancy isolation.
  • Team plan gates collaboration; Enterprise gates report render.

Built-in guarantees

Content-addressed artifacts

  • All bytes are stored as sha256:<hash> objects.
  • Runs reference hashes, enabling dedupe and integrity checks.

Tamper-evident audit

  • Append-only audit entries chained by SHA-256.
  • Any mutation is detected on read/verify.

Deterministic verification

  • Seeded replay for repeatable outputs.
  • Optional Enterprise: deterministic Markdown validation report.
